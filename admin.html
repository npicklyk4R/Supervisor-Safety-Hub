Site Editor

This page edits your live site directly by committing to your GitHub repo. Connect once per browser with a Personal Access Token scoped to just this repository.

How do I create a token?
  1. Go to github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens, then Generate new token.
  2. Under Repository access, choose Only select repositories and pick this repo — don't grant access to all repos.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as No access.
  4. Set an expiration (90 days is a reasonable default — you'll just generate a new one when it lapses).
  5. Generate the token and paste it above. GitHub only shows it once, so keep the tab open until you've connected.

App text

Logo

Upload a square-ish logo (PNG, JPG, or SVG). On publish, it's resized and committed as logo.png (512×512, transparent background) — replacing the file the header reads directly, so no other code needs to change.

Brand colors

These drive every gradient, button, and accent throughout the app. Category accents (Reporting Tools, CRP Hiring & Performance, Submissions & Inspections) are derived automatically from Yellow→Green→Blue→Purple.

Forms

Categories are created automatically from whatever you type into "Type of Form" — there's no separate place to manage them. Drag rows using the handle to reorder.

Publish changes

Clicking Publish to GitHub commits your changes directly to the main branch of your repo. GitHub Pages picks up the new commit and republishes automatically — usually within a minute, no separate deploy step.
